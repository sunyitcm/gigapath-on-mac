# Validation and use limits

| Component | Actual checks | Not validated |
| --- | --- | --- |
| Retained source and public derivatives | Static syntax and correspondence of retained definitions; derivatives explicitly identified | New extraction, model execution or arbitrary-device portability |
| Planner / CPU-comparison CLI | Static checks | H5 comparison execution for this supplement |
| Scalar report/plot helper | Executed on existing published CSV/JSON; matching-run C8 shares, Mac same-reference ratios and pair-count relationships checked | Recomputed array metrics, controlled timing or pixel-identical historical plots |
| Scientific configurations / recorded environments | Fields retained from the recorded study contracts/environments; missing fields marked | Clean installation, complete dependency closure or a universal lockfile |
| Worker excerpts | Scientific bodies retained with omitted context identified | Standalone workers or a complete end-to-end workflow |

The historical single-task derivative supports GigaPath only. No Virchow2 or TITAN/CONCH loader is supplied. The included blocked-attention component accepts CPU/MPS and does not provide the full CUDA/LongNet integration. External models, weights, source slides and feature arrays are not bundled.

M5 E9 source identity applies to the formal batch; it does not identify the batch/repeat producing each historical final H5 or establish the historical M3 executable. Some HDF5/OpenSlide C-library, OS and driver versions were not recorded. End-to-end execution and clean-environment installation remain unvalidated. Static checks and published-scalar checks do not establish predictive equivalence or causal mechanisms.
