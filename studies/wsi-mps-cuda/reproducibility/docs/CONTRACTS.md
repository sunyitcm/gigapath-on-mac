# Precision, timing, resources and comparison contracts

The [snapshot methods](https://github.com/sunyitcm/gigapath-on-mac/blob/0fe0b1f408c51580b61be9b2ab826ceedffa175a/studies/wsi-mps-cuda/METHODS_AND_MEASUREMENT_CONTRACTS_EN.md) and [configurations](../configs/) describe separate observation families, not one controlled full factorial design.

M5 E9 `t_encode_s` extends through MPS end synchronization. Do not apply that boundary to all historical M3 records. `t_total_s` is the formal traversal, outside H5 save. |

Both enclose model and Original postprocess; synchronization after context | B8; 10 discarded warm-up batches; r1 per policy. A saved float32 feature does not establish FP32 internal execution. Dtype observations at module boundaries do not identify every kernel or accumulator. Training precision and inference policy are different layers; neither pretraining precision nor final-array equality establishes an internal rounding cause.

Preprocessing is the retained extractor: ordered level-0 lattice, HSV saturation mask, morphological close and component area cutoff; tissue fraction threshold; RGB read/convert; pen rule replaces rejected tiles by white without deleting coordinates; original model transform and Original postprocess. GigaPath output is1536; Virchow2 concatenates CLS1280 and non-register patch mean1280; CONCH v1.5 output is768. `MTHRESH`/hole-related constants retained in historical config are not silently inserted into the actual mask function. Aligned coords alone do not prove equal RGB/tensors.

C8 and precision output resources are **event sampled** before traversal, at batch1, every50 batches, last batch and after traversal. Duplicate event queries are possible at coinciding boundaries. Not fixed Hz; event maxima need not capture a physical peak. CPU user/system seconds and one-core100% CPU percentage belong to the stated sampler/output scope (query overhead included), not every individual phase. Values can exceed100% with multiple threads. RSS sampled maximum differs from process-lifetime OS HWM. MPS allocated/driver counters differ from CUDA allocated/reserved; CUDA allocator maxima are API values after reset following warmups with surviving allocations still live. None is a universal physical memory peak. The historical driver field is an end query despite its old name. Aggregation monitors have their own saved polling/boundary contract and must not inherit C8's event rule.

Host-wall stages include combined calls and waits: RGB, white check, transform, stack/device submission, forward/postprocess/end-sync, readback/collection/concatenation, and unattributed wall. Stage shares use matching-run stage sums divided by matching full-output wall sums, never sums of unrelated medians. Low CPU percentage does not diagnose GPU starvation; high forward share does not establish saturation. Device activity, host waiting and kernel/transfer causes are not isolated.

CPU feature comparison first checks full shape/dtypes and row-by-row coordinates; it does not sort, intersect, truncate or delete tiles. Full arrays remain in original order. Float64 block256 arithmetic computes global/tile norms, cosine, MAE/RMSE/max_abs and locations. Relative L2 is Frobenius error / reference Frobenius norm. Zero norms/SSE produce undefined fields where specified, not invented zero error. Tile SSE sorting is descending with ascending row-index ties; exactly ceil(.01N) rows contribute to top1%. Quantiles use the retained NumPy quantile method (default linear/type7). The mean loop accumulates each 256-row float64 chunk sum, in original order, and divides once by N without normalization or reselection.

Five WSIs, technical workers, within-lifecycle calls, reference rows and physical pairs are distinct units. Tiles are not independent patients. High cosine or exact stored-array equality is not clinical/prediction equivalence. Highest SSE is not pathologic importance. Independent top sets differ. A lower total error can coexist with more concentrated residual error.

Historical comparisons used the retained `historical_compare.py`512-row algorithm with first-matrix norm, while later precision comparisons use the256-row comparator. C8 retained CPU cosine summaries clip roundoff for specified distribution/global fields and also preserve raw witnesses; the later comparator reports its retained raw quantile convention. These are distinct implementations, not a retrospective uniform recomputation. Historical stratum summaries use the located `historical_statistics.py` type7 quantile/median functions. Their raw timing/WSI-ratio inputs are not newly distributed by this code supplement.
